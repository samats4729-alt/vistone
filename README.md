# VISTONE — сайт и админка

Сайт-каталог крупноформатных ультратонких плит VISTONE для дизайнеров и архитекторов:
зашёл → нашёл материал → увидел характеристики, цену, наличие и сроки → понял свои условия → написал менеджеру.

Всё, что видно на сайте, меняется в админке по адресу **`/admin`** — без программиста.

## Что есть на сайте

| Раздел | Адрес | Что там |
|---|---|---|
| Главная | `/` | Что такое VISTONE, крупный формат, ультратонкие плиты, коллекции, для дизайнеров, как проходит работа, ЖК, контакты, кнопка «Получить консультацию» |
| Каталог | `/catalog` | Все коллекции, поиск и фильтры: серия, тип материала, цвет, фактура, размер, толщина, цена, наличие |
| Карточка коллекции | `/catalog/<название>` | Фото, фактура, цвет, размеры, толщина, состав, страна, производство, характеристики, цена, наличие, срок поставки, расчёт по проекту |
| Калькулятор | `/calculator` | Площадь + материал → сколько плит, ориентировочная стоимость и бонус дизайнера |
| Наличие и сроки | `/stock` | Есть ли сейчас → сколько м² → когда получить → срок поставки |
| Дизайнерам | `/designers` | Преимущества работы, бонус, шаги работы |
| ЖК и застройщикам | `/developers` | Коммерческое предложение для объектов |
| Контакты | `/contacts` | Менеджеры, WhatsApp, шоурум, Instagram |

У каждой коллекции своя ссылка — её можно переслать клиенту в WhatsApp. Кнопки «Написать» открывают WhatsApp
с уже набранным сообщением: какая коллекция и какой расчёт.

## Что настраивается в админке

- **Коллекции** — добавить, изменить, скрыть, дублировать, удалить. Фото (несколько, первое — главное),
  артикул, серия, тип, цвет, фактура, размеры, толщина, состав, страна, производство, характеристики, описание.
- **Цены и наличие** — одна таблица на все коллекции: цена, остаток, когда можно получить, срок поставки,
  ожидаемое поступление. Удобно обновлять раз в неделю.
- **Серии** — названия, описания, обложки, порядок.
- **Главная страница** — заголовок, фото, тексты, преимущества, «Где применяется».
- **Разделы сайта** — «Дизайнерам», «Как проходит работа», «ЖК и застройщикам».
- **Контакты** — менеджеры с телефонами и WhatsApp, адрес шоурума, часы работы, Instagram, карта.
- **Настройки** — процент бонуса дизайнера, запас на подрезку, порог «осталось мало», общие характеристики
  для всех коллекций, тексты для поиска Google, смена пароля, резервная копия.

Как сайт показывает наличие:

| В админке | На сайте |
|---|---|
| Остаток пустой | «Наличие уточняйте» |
| Остаток 0 | «Под заказ» + срок поставки |
| Остаток меньше порога (по умолчанию 30 м²) | «Осталось N м²» |
| Остаток больше порога | «В наличии N м²» |
| Цена пустая | «Цена по запросу» |

## Запуск на своём компьютере

Нужен Node.js 20 или новее.

```bash
npm install
ADMIN_PASSWORD='придумайте-пароль' npm start
```

Сайт откроется на http://localhost:3000, админка — http://localhost:3000/admin.

Если `ADMIN_PASSWORD` не указать, при первом запуске сайт сам придумает пароль и напечатает его в консоли.
Потом пароль меняется в админке → Настройки.

## Размещение в интернете

Все данные сайта — коллекции, тексты, пароль и загруженные фото — хранятся в папке `data/`
(путь меняется переменной `DATA_DIR`). **Эта папка должна лежать на постоянном диске** — иначе после перезапуска
сервера изменения из админки пропадут.

### Вариант 1. Свой сервер (VPS) с доменом vistone.kz

Подойдёт любой VPS с Docker (например, ps.kz или hoster.kz). В `Caddyfile` впишите свой домен,
в настройках домена направьте его на IP сервера, затем:

```bash
git clone https://github.com/samats4729-alt/vistone.git
cd vistone
ADMIN_PASSWORD='придумайте-пароль' docker compose up -d
```

Caddy сам получит HTTPS-сертификат. Данные хранятся в Docker-томе `vistone_data`.

Обновить сайт после изменений в репозитории:

```bash
git pull && docker compose up -d --build
```

### Вариант 2. Render.com

В Render: New → Blueprint → выберите этот репозиторий. Настройки уже описаны в `render.yaml`
(нужен тариф с диском — Starter). Пароль для первого входа укажите в переменной `ADMIN_PASSWORD`.

## Резервные копии

- В админке: Настройки → «Скачать резервную копию» — файл со всеми коллекциями, текстами и настройками.
- Полная копия вместе с фото — скопировать папку `data/`. Для Docker:

```bash
docker run --rm -v vistone_vistone_data:/data -v "$PWD":/backup alpine tar czf /backup/vistone-data.tgz -C /data .
```

## Для разработчика

```
server.js            маршруты сайта и API админки
src/store.js         хранилище: data/db.json, атомарная запись, копия прошлой версии в db.prev.json
src/auth.js          пароль (scrypt), сессии, ограничение попыток входа
src/validate.js      проверка всего, что приходит из админки
src/images.js        загрузка фото: проверка формата, уменьшение до 2000 px (если установлен sharp)
src/render/          HTML-страницы сайта (рендерятся на сервере — сайт индексируется поисковиками)
public/              стили и скрипты сайта и админки
seed/                стартовый каталог: 54 коллекции и фото, копируются в data/ при первом запуске
test/                автотесты: npm test
```

Стартовый каталог собран из PDF-каталога VISTONE (части 3, 4, 7, 8, 9). Фотографии плит в PDF небольшие —
около 250 px по ширине, поэтому лучше заменить их в админке на оригиналы от поставщика.
